## 🛠️ Características del Proyecto
- **Estructura Semántica**: Uso de etiquetas HTML5 (`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`).
- **Layout en CSS**: Posicionamiento totalmente basado en **Flexbox** y variables globales (`:root`).
- **Diseño Responsive**: Adaptación fluida a dispositivos móviles mediante `@media queries`.
- **Estandarización**: Normalización con `Normalize.css` e inclusión de reset CSS global.
- **Usabilidad & Accesibilidad**: Atributos `alt` descriptivos en imágenes y etiquetas `aria-label` en enlaces interactivos.
- **Recursos Externos**: Iconos desde *Font Awesome*, tipografía *Inter* desde Google Fonts y favicon en formato vectorial SVG.
